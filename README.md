# 给生活的答案

一个手机端优先、无需登录、数据只保存在本地的互动答案册。用户可以从成长、生活、关系与现实等主题中选择一组问题，用选择题快速回答，或亲手写下自己的答案，最后生成适合保存和分享的完整图片或 Word 答案册。

> 在线体验：[给生活的答案 · GitHub Pages](https://91vrvd.github.io/answers-for-life/)

![给生活的答案分享封面](./public/og-v5.png)

## 产品特点

- 手机端优先，主要适配 375px–430px，桌面端居中显示手机宽度内容。
- 不注册、不登录，不接后端，答案仅保存在当前设备。
- 每个主题固定使用更合适的回答方式，用户不用额外判断题型。
- 可选择本次回答数量，并从不同分类中均衡抽题。
- 自动保存当前题目、答案和进度，刷新或退出后可以继续。
- 未完成答案时，首页同时提供“继续刚才的答案”和“选择其他主题”。
- 选择题结果可导出包含全部答案的多页 PNG。
- 写作题结果可导出完整 PNG 和可继续编辑的 Word 答案册。
- 导出图片带有产品水印，便于分享后找到原产品。
- 网页版和原生微信小程序共用同一套主题数据。

## 使用流程

### 选择题主题

```text
首页 → 选择主题 → 选择题量 → 逐题选择 → 查看全部答案 → 生成多页图片
```

### 自己写主题

```text
首页 → 选择主题 → 选择题量 → 逐题书写 → 查看全部答案 → 导出图片或 Word
```

答题过程中可以随时保存进度并返回首页。回到首页后既可以继续原主题，也可以选择其他主题。

## 隐私与数据

- 网页版使用浏览器 `localStorage` 保存答案和进度。
- 小程序版使用微信本地存储 API 保存答案和进度。
- 当前版本没有用户系统、数据库、统计接口或云端同步。
- 题目选择、用户输入和导出过程都在当前设备完成。
- 页面会明确提示：“仅在本地运行 · 内容不会上传服务器”。
- 导出的图片和 Word 文件只有在用户主动保存或分享后才会离开应用。

## 本地运行网页版

环境要求：Node.js 22.13 或更高版本。

```bash
git clone https://github.com/91vrvd/answers-for-life.git
cd answers-for-life
npm install
npm run dev
```

默认打开：`http://localhost:3000`

常用命令：

```bash
npm run dev       # 启动开发环境
npm run build     # 生成生产构建
npm test          # 构建并运行题库与渲染测试
npm run lint      # 运行代码检查
npx tsc --noEmit  # TypeScript 类型检查
```

## 运行微信小程序

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库中的 `miniprogram/`。
4. 体验代码可以使用游客模式；预览和上传需填写自己的小程序 AppID。
5. 确保当前微信号已被添加为对应小程序的开发者。

开源仓库中的 `miniprogram/project.config.json` 默认使用：

```json
{
  "appid": "touristappid"
}
```

请不要把 AppSecret、访问令牌、Cookie 或其他凭据提交到仓库。

## 同步题库到小程序

网页主题数据是题库的主要来源。修改 `src/data/themes.ts` 后运行：

```bash
node scripts/build-miniprogram-data.mjs
```

脚本会重新生成 `miniprogram/data/themes.js`，使网页版和小程序保持一致。

## 导出说明

### 完整图片

答案会根据内容长度自动分页，每页保持统一的暖白、豆沙红与鼠尾草绿视觉语言。所有已选题目和答案都会被写入图片，避免只保存当前一题。

### Word 答案册

Word 导出仅对“自己写”主题开放。文件包含：

- 主题封面；
- 本轮全部问题；
- 用户已经写下的答案；
- 留空题目的继续填写区域；
- 统一的颜色、页脚和品牌样式。

## 当前边界

- 没有真实登录、支付、微信授权或云端数据库。
- 没有跨设备同步；更换设备后不会自动出现旧答案。
- 没有真实双人实时匹配或共同编辑。
- 小程序正式发布仍需开发者在微信公众平台提交审核。
- 题目用于自我记录和交流，不替代医疗、心理、法律或财务专业建议。
