# 关于爱的100件小事

手机端优先的情侣互动网页原型。用户可以填写对方称呼、完成 15 项爱情小事选择、查看个人结果、生成模拟邀请，并进入双人共同答案及「100 件小事」占位页面。

## 本地运行

```bash
npm install
npm run dev
```

默认打开 `http://localhost:3000`。

生产构建与测试：

```bash
npm test
```

## 主要目录

```text
app/                 页面入口、元数据与全局样式
src/components/      按钮、进度、任务卡、邀请卡、底部导航等组件
src/data/            15 条任务数据及类型
src/screens/         八个产品流程视图
src/state/           Context、reducer 与 localStorage 持久化
src/utils/           个人结果与双人匹配计算
tests/               服务端渲染冒烟测试
```

## 原型边界

- 数据仅保存在当前浏览器的 `localStorage` 中。
- “模拟 TA 已完成”使用内置预设答案，不连接真实用户。
- 复制邀请链接为本地模拟链接，不接微信分享接口。
- 保存邀请卡/生成结果卡目前提示用户使用系统截图。
- 共同打卡、照片、留言和回忆时间轴为下一阶段入口。
