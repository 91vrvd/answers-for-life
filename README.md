# 关于爱的100件小事

手机端优先的爱情互动网页原型。产品内置 100 个行动主题，每个主题都有「和 TA 一起」与「好好爱自己」两套独立文案。除此之外，还提供情侣与自爱两套原创开放式真心问答，以及可自由打卡和修改内容的「30天全新自己挑战」。答案和挑战进度均可保存为竖版 PNG 分享卡。

## 本地运行

```bash
npm install
npm run dev
```

默认打开 `http://localhost:3000`。

生产构建与测试：

```bash
npm test
```

## 主要目录

```text
app/                 页面入口、元数据与全局样式
src/components/      按钮、进度、任务卡、邀请卡、底部导航等组件
src/data/            100 个双模式任务、均衡随机抽题逻辑及类型
src/screens/         模式、题量、答题与结果等产品流程视图
src/state/           Context、reducer 与 localStorage 持久化
src/utils/           个人结果与双人匹配计算
tests/               服务端渲染冒烟测试
```

## 原型边界

- 数据仅保存在当前浏览器的 `localStorage` 中。
- 每轮从 100 题中按分类均衡随机抽取，题目 ID 会保存在本地，刷新不会重新随机。
- 「12分钟真心问答」可选 3、6 或 12 题，答案自动保存在本机；完成后可选择任一答案生成 1080×1440 PNG 卡片。
- 「30天全新自己挑战」不要求连续或按顺序完成，支持随机抽取今日任务、逐项自定义、筛选进度，并生成 1080×1440 PNG 进度卡。
- “模拟 TA 已完成”使用内置预设答案，不连接真实用户。
- 复制邀请链接为本地模拟链接，不接微信分享接口。
- 保存邀请卡/生成结果卡目前提示用户使用系统截图。
- 共同打卡、照片、留言和回忆时间轴为下一阶段入口。
